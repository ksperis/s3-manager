# Portal: Files

Use this page when you work with files inside a Portal Storage Space.

## Before you start

- Open the right Portal account and Storage Space.
- Your Storage Space role allows the action you want to perform.
- The Storage Space is active, not archived.

## Main tasks

| Task | Where | Notes |
|---|---|---|
| Browse folders | Storage Space object list | Breadcrumbs and folder rows keep navigation scoped to the selected Storage Space. |
| Upload files | Object list action bar | Available for Editor and Owner roles when storage permissions allow writes. |
| Download files | Object row or detail page | Available when your role and storage permissions allow reads. |
| Create folders | Object list action bar | Creates a prefix marker or equivalent folder representation. |
| Delete files | Object row actions | Available only for roles that can write/delete. |
| Inspect safe details | **Details** | Shows safe metadata, preview state, and quick actions without advanced Browser tools. |

## You are done when

The object list reflects the new upload, folder, deletion, or download-ready object without leaving the Storage Space.

## If an action is hidden

Viewer spaces hide upload, folder creation, and delete actions. Archived spaces hide file browsing entirely. Advanced object features such as versions, tags, raw headers, retention, and diagnostics belong in Browser or Manager.
